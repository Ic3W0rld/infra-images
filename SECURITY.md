# Security Policy

This repository mirrors container images to GHCR. It is **read-only for the public**.

## Reporting a Vulnerability

If you discover a security issue (e.g. a mirrored image with a known CVE, a secret accidentally committed), please email **ic3cryst4l@proton.me** rather than opening a public issue.

## Scope

- Image mirroring workflow: `.github/workflows/mirror.yaml`
- Image manifest: `mirrors.yaml`
- No application code is hosted here.
